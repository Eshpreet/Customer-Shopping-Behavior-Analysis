# Customer Shopping Behavior Analysis

## Project Overview
An end-to-end data analytics project focused on analysing customer shopping behaviour, purchasing patterns, and spending trends using Python, SQL, and Power BI.

## Technologies Used
- Python
- Pandas
- NumPy
- SQL
- MySQL
- Power BI

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL-Based Data Analysis
5. Power BI Dashboard Development
6. Business Insights and Recommendations

## Project Files
- `Dataset/` – Customer shopping behaviour dataset.
- `Python/` – Python analysis notebook.
- `SQL/` – SQL queries.
- `PowerBI/` – Interactive Power BI dashboard.

## Key Analysis Areas
- Customer demographics and purchasing behaviour.
- Product category performance.
- Sales and revenue trends.
- Payment methods and shipping preferences.
- Customer subscriptions and discounts.
- Customer ratings and satisfaction.
